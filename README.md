# One-Day Trips from Nagoya

A simple trip-planning web page for exploring destinations in and around Nagoya. It was created as the final task for an Advanced Service Engineering class.

## Trip Routes

The page includes three selectable one-day trips:

- **Nagoya City** - Nagoya Station, Nagoya Castle, Osu, Sakae, Oasis 21, and MIRAI TOWER
- **Ghibli Park** - Nagoya Station, Fujigaoka, Ai-Chikyuhaku Kinen Koen, Ghibli Park, and Oasis 21
- **Nagoya Port** - Nagoya Station, Nagoyako Station, the Port of Nagoya Public Aquarium, the Fuji Antarctic Museum, the Nagoya Port Building, and Sakae

Selecting a trip updates the route map, markers, schedule, and trip summary.

## Features

- Responsive layout using Bootstrap
- Interactive map using Leaflet and OpenStreetMap
- Markers and popup messages for each destination
- Polylines showing the suggested visiting order
- Circles and polygons showing areas around major destinations
- Three selectable trip plans
- Suggested schedules for each trip

## Technologies

- HTML
- CSS
- Bootstrap 5.3
- Leaflet 1.9
- OpenStreetMap
